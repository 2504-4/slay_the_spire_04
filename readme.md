# 杀戮尖塔3

## 项目简介

这是一个使用 Java 17 与 JavaFX 制作的回合制卡牌冒险基础版。玩家以冒险者的身份按照地图路线击败最终boss。

## 实现功能

中文界面展示双方生命、护甲、玩家能量、抽牌堆/弃牌堆、手牌、消耗牌堆、敌人意图和战斗记录。
三类卡牌：攻击牌、技能牌、能力牌；胜利后还有三张随机候选奖励卡。
每回合抽五张、获得三点能量；打出或回合结束卡牌会进入弃牌堆，抽牌堆空时自动洗入弃牌堆继续抽牌。
点击手牌出牌，能量不足会在日志中提示且不会使用该牌；结束回合后敌人依照交替的攻击/护甲意图/增益意图行动。
数场战斗；胜利时选择一张奖励加入牌组，boss关战胜利通关；死亡或通关后均可重新开始。
覆盖了无能量、空牌堆循环、死亡状态、选奖励与重开等规则分支。敌人行动前会在界面显示下一步意图。

## 运行环境

JDK：**17**（`pom.xml` 已以 `maven.compiler.release=17` 编译）。
JavaFX：`org.openjfx:javafx-controls:17.0.10`
Maven：建议 3.9 或更新版本；
