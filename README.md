# 杀戮尖塔 JavaFX 简化版

## 项目简介

这是一个使用 Java 17 和 JavaFX 编写的回合制卡牌战斗示例。玩家通过打出攻击牌和防御牌与敌人战斗。

## 已实现功能

- 显示玩家与敌人的生命值、格挡、玩家能量、抽牌堆、弃牌堆和战斗提示。
- 初始牌组包含 5 张“打击”和 4 张“防御”。
- 每回合获得 3 点能量并抽 5 张牌。
- 抽牌堆为空时，将弃牌堆洗回抽牌堆。
- 打出攻击牌可造成伤害，打出防御牌可获得格挡。
- 结束回合后敌人攻击；格挡会先吸收伤害，然后开始下一回合。
- 敌人或玩家生命值降到 0 时结束战斗。

## 运行环境

- JDK 17 或更新版本
- Maven 3.9 或更新版本
- JavaFX 17.0.20（由 Maven 自动管理）

## 构建与运行

```bash
mvn clean test
mvn javafx:run
```

程序入口为 `org.Main`。
